# splitwise-clone
Splitwise Clone with Live Payment Gateway – A full-stack expense sharing application where users can split bills, track balances, and settle debts securely through Razorpay integration. Built with React, Node.js, PostgreSQL, Docker, and Kubernetes.  -In Progress



### Start the Frontend

> Change into the frontend folder
```
cd Frontend\Splitwise-Clone
```
> Install all the packages
```
npm install
```
> Run the frontend
```
npm run dev 
```


### Start the Backend
> Change into the backend folder
```
cd Backend
```
> Install all the packages
```
npm install
```
> Run the frontend
```
npm run dev 
```
